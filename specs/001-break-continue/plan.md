# Implementation Plan: Break and Continue Keywords

**Branch**: `001-break-continue` | **Date**: 2025-11-18 | **Spec**: [spec.md](./spec.md)

## Summary

Add `break` and `continue` keywords to PHP Script for loop control. This feature enables developers to exit loops early (`break`) or skip to the next iteration (`continue`), with optional numeric level parameters for nested loop control (e.g., `break 2`, `continue 3`). The implementation extends the Lexer to recognize new keywords, the Parser to handle new statement types with optional parameters, and the AstTraverser to track loop context and execute control flow changes. Editor integration will provide syntax highlighting, code completion, and linting for the new keywords.

## Phase 1: Data Model & Contracts

**Prerequisites**: research.md complete

### Data Model

**File**: `specs/001-break-continue/data-model.md`

#### AST Nodes

1. **BreakStatement**
   - Extends: `BaseNode` (implements `Node`)
   - Properties:
     - `level: int` - Number of loop levels to break (default: 1)
   - Methods:
     - `__construct(int $level = 1)` - Constructor with level validation
     - `accept(AstTraverserInterface $traverser)` - Visitor pattern method
     - `getLevel(): int` - Getter for level
   - Validation: Level must be positive integer

2. **ContinueStatement**
   - Extends: `BaseNode` (implements `Node`)
   - Properties:
     - `level: int` - Number of loop levels to continue (default: 1)
   - Methods:
     - `__construct(int $level = 1)` - Constructor with level validation
     - `accept(AstTraverserInterface $traverser)` - Visitor pattern method
     - `getLevel(): int` - Getter for level
   - Validation: Level must be positive integer

3. **LoopContext** (Internal to AstTraverser)
   - Properties:
     - `depth: int` - Current loop nesting depth
   - Methods:
     - `enterLoop(): void` - Increment depth when entering loop
     - `exitLoop(): void` - Decrement depth when exiting loop
     - `validateBreakLevel(int $level): void` - Validate break level is valid
     - `validateContinueLevel(int $level): void` - Validate continue level is valid

### Contracts

**Directory**: N/A (no external API contracts needed)

Break and continue are language features, not external APIs. The contracts are internal to the language implementation:

- **Lexer Contract**: Must recognize `break` and `continue` as keywords
- **Parser Contract**: Must parse `break [level]` and `continue [level]` syntax
- **AstTraverser Contract**: Must execute break/continue and maintain loop context
- **PhpScriptRenderer Contract**: Must render break/continue back to source

These are captured in the existing interfaces (`LexerInterface`, `ParserInterface`, `AstTraverserInterface`) and don't require new contract files.
