PHP Script is a scripting language that allows end-users to customize and extend your PHP-powered backend with the simplicity of JavaScript. It provides a secure and controlled environment to execute user-generated scripts without the need for a separate Node.js service.

This documentation will guide you through the process of integrating PHP Script into your application. Whether you're a developer looking to add customization features or a user writing scripts, you'll find everything you need here.

## Where to start?

-   If you're new to PHP Script and want to understand the "why" behind it, start with the **[Introduction](./introduction.md)**.
-   If you're a developer looking to integrate PHP Script into your application, check out the **[PHP Guide](./php/)**.
-   If you're looking for a reference on the scripting language itself, head over to the **[Language Guide](./language/)**.
